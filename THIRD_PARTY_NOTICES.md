# Third-party review inventory

MD-SOP uses PyTorch, NumPy, SciPy, pandas, matplotlib, PyYAML and pyarrow; feature preparation uses ESM-C/its model weights and HH-suite/database resources. Original SOPPCL and the earlier MD-SOP feature-preparation pipeline are part of the scientific provenance. Third-party packages, pretrained weights, databases and raw structures/labels are not bundled into this code repository.

This inventory is not a complete license analysis. Before public distribution, review the actual licenses/attribution and any output/weight redistribution conditions for the exact versions and data sources used. Do not automatically apply the project's future software license to upstream assets or claim that code licensing alone makes all data/weights redistributable.

Historical comparator scores are identified as references, not a reimplementation claimed as new MD-SOP work. Source hashes distinguish unchanged archived scientific code from newly added packaging/inference wrappers.
